# K Bhavyashree Portfolio

A clean, responsive personal portfolio website built with plain HTML, CSS, and JavaScript. It showcases a developer/student profile with personal bio, education details, career objective, and social links.

## Overview

This project is a lightweight static website designed to present a professional online profile. It is ideal for personal branding, portfolio introductions, and quick online presence without needing a framework or build tooling.

## Features

- Responsive single-page layout
- Profile card design with personal information
- Education and career objective sections
- Social media and contact links
- Clean modern styling using CSS
- Lightweight JavaScript for theme detection and smooth scrolling behavior

## Project Structure

```text
.

```

## Run Locally

Since this is a static website, you can open it directly in a browser or run a local web server.

### Option 1: Open directly

- Open `index.html` in your browser.

### Option 2: Use a simple local server

From the project folder, run:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment

This website is ready to be deployed on GitHub Pages or any static hosting provider.

### GitHub Pages

1. Push this repository to GitHub.
2. Open the repository settings.
3. Navigate to Pages.
4. Select the branch to deploy (for example, `main`).
5. Save the configuration.

Your site will be published at a URL similar to:

```text
https://<your-username>.github.io/<repository-name>/
```

## Customization

You can update the content in `index.html` to change:

- Name
- Profile image
- About section
- Education details
- Career objective
- Social links
- Contact information

You can also update colors, spacing, and layout in `styles.css` to match your preferred style.
